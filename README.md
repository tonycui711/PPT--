# PPT制作

开源 Agent Skill：用六步提示词链做简报——**先出文字、分步确认，全部确认后再产出 `.pptx`**。

面向通用场景，不绑定单一品牌。品牌色与风格优先从用户提供的 logo / 样张推断，推断不出再询问。

## 何时使用

用户说「做 PPT」「做简报」「做演示文稿」「PPT制作」，或需要先出蓝图再生成 pptx 时。

## 六步

1. **建立完整简报蓝图** — 目的、受众、核心讯息、页数与叙事顺序  
2. **规划投影片结构与流程** — 逐页标题、目的、核心讯息、前后衔接  
3. **打造吸引人的故事线** — 开场 → 问题 → 洞察 → 方案 → 行动  
4. **产出视觉与版面指引** — 按品牌色与风格做逐页版面建议  
5. **生成每一页的完整内容** — 可直接贴进幻灯片的文案  
6. **精简并提升清晰度** — 每页只讲一件事，附修改说明  

每步结束后等待用户确认，再进入下一步。06 确认后才生成 `.pptx`。

## 安装

把本目录（或至少 `SKILL.md`）放到你的 Agent skills / workflows 目录，按你所用产品的 skill 加载方式启用。Cursor / Grok Bot 一类产品通常识别带 YAML frontmatter 的 `SKILL.md`。

## 语言

默认简体中文。
