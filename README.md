# PPT制作

开源 Agent Skill：整条链路为 **文案锁字 → 视觉锁版 → 出片岗出 `.pptx`**。默认简体中文，不绑定单一品牌。

面向可分工的 Agent 团队：文案岗／视觉岗负责打磨（建议 ≥3 轮且调度先审），出片岗只在闸门全绿后生成 pptx。称谓统一用「投影片／简报」，不用「影片」。

## 何时使用

用户说「做 PPT」「做简报」「做演示文稿」「PPT制作」，或需要跑简报流水线直至产出 pptx 时。

## 流水线（旧六步重挂）

| 步 | 内容 | 建议执行 |
|----|------|----------|
| 01 | 完整简报蓝图 | 文案岗 |
| 02 | 投影片结构与流程 | 出片岗 |
| 03 | 故事线 | 文案岗 |
| 04 | 视觉与版面指引 | 视觉岗 |
| 05 | 逐页完整内容 | 文案岗 |
| 06 | 精简清晰度 | 文案岗 |
| 出片 | 生成 `.pptx`（含单击 Appear） | 出片岗（闸门全绿后） |

出片前硬闸门：锁版文案、锁版视觉指引、已确认投影片结构。改字回文案岗，改好看回视觉岗，执行瑕疵由出片岗改。

## 安装

把本目录（或至少 `SKILL.md`）放到你的 Agent skills / workflows 目录，按你所用产品的 skill 加载方式启用。Cursor / Grok Bot 一类产品通常识别带 YAML frontmatter 的 `SKILL.md`。

## 语言

默认简体中文。
